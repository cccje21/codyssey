# 실행 로그 v1

## 작업 기록 순서

### 작업 1. 과업 선정 및 정의
- 프로그램 운영 안내문 작성 과업 선정
- 대상 사용자와 업무 목적 설정

### 작업 2. 프롬프트 설계
- 프로그램 운영 안내문 작성 페르소나 설정
- 시스템 프롬프트 및 유저 프롬프트 작성
- Few-shot 예시 3건 제작
- 재사용 가능한 운영 정보 입력 템플릿 작성

### 작업 3. 프롬프트 실험
- Zero-shot 방식으로 안내문 작성 실험
- Few-shot 예시를 적용한 결과 비교
- 단계적 작업 지침을 추가하여 결과 비교

### 작업 4. 재사용 입력 템플릿 테스트
- 새로운 가상 프로그램 정보 작성
- 입력 템플릿에 운영 정보 입력
- 새로운 대화창에서 안내문 생성 및 결과 확인

### 작업 5. 환각 검증
- 프로그램 일정, 장소, 참가비 등 사실 확인 질문 진행
- 제공되지 않은 환불 규정 및 진행자 정보 질문
- 실제 답변을 기준으로 Pass/Fail 판정

### 작업 6. 실행 결과 분석
- 환각 및 문맥 끊김 발생 여부 확인
- 동일 입력 반복을 통한 답변 일관성 확인
- 프롬프트 개선 사항 정리
