# 디즈니 애니메이션 티어리스트 기획서

## 1. 누가 쓰나
- 지인(친구) 그룹의 구성원들
- 각자 자신의 디즈니 영화 취향을 정리하고, 서로 공유하고 싶은 사람

## 2. 무엇을 하려고
- 디즈니 애니메이션 작품들을 등급별로 분류해 **자신의 영화 취향을 시각화**
- 완성한 티어리스트를 **지인끼리 공유**하여 서로의 취향을 비교

## 3. 화면과 동작

### 화면 구성
- **상단**: 영화 검색/추가 입력창, JSON 내보내기/불러오기 버튼, 전체 초기화 버튼
- **중앙**: 티어 등급 영역 (S / A / B / C / D, 5단계)
- **하단**: 미분류 영화 풀(pool)

### 색상 (파스텔톤)
- **배경**: 노랑/붉은색 계통의 파스텔톤
- **티어별 색상** (위에서부터)
  - S: 빨강 (파스텔)
  - A: 주황 (파스텔)
  - B: 노랑 (파스텔)
  - C: 초록 (파스텔)
  - D: 파랑 (파스텔)
- **풀(pool)**: 보라 (파스텔)

### 주요 동작
- 하단 풀에 있는 영화 카드를 **드래그 앤 드롭**으로 원하는 티어에 배치
- 티어에 배치된 카드도 다른 티어로 **자유롭게 이동** 가능
- 검색창에 영화 제목을 **자유 입력**하면 새 카드가 생성되어 풀에 추가됨
  - **중복 추가 방지**: 이미 존재하는 영화 제목은 추가되지 않음
- 각 카드에서 **삭제** 가능 (실수로 추가했거나 원치 않는 영화 제거)
- **전체 초기화** 버튼으로 모든 배치와 추가 영화를 초기 상태로 되돌릴 수 있음
- 작업 내용은 **자동으로 브라우저에 저장**되어, 다시 열어도 그대로 유지됨 (localStorage)
- **JSON 파일로 내보내기** → 친구에게 전달
- 받은 **JSON 파일을 불러오기** → 친구의 티어리스트를 같은 사이트에서 확인

### 지원 범위
- **데스크톱 브라우저 전용** (모바일 지원 없음)

## 5. 완성 기준
- [ ] S/A/B/C/D 5단계 티어 영역이 지정된 색상(빨/주/노/초/파 파스텔톤)으로 표시됨
- [ ] 미리 준비된 디즈니 영화 20편이 하단 풀(보라 파스텔톤)에 표시됨
- [ ] 배경이 노랑/붉은색 계통 파스텔톤으로 적용됨
- [ ] 드래그 앤 드롭으로 카드를 티어에 배치할 수 있음
- [ ] 검색창에 자유 입력하여 새 영화 카드를 추가할 수 있음
- [ ] 이미 존재하는 영화는 중복 추가되지 않음
- [ ] 각 카드를 개별 삭제할 수 있음
- [ ] 전체 초기화 버튼으로 초기 상태로 되돌릴 수 있음
- [ ] 브라우저를 닫았다 열어도 작업 내용이 유지됨 (localStorage 자동 저장)
- [ ] JSON 파일로 내보내기 기능이 동작함
- [ ] JSON 파일을 불러와서 티어리스트를 복원할 수 있음
- [ ] 서버 없이 HTML 파일 하나로 실행됨
- [ ] 데스크톱 브라우저에서 정상 동작함
