# PIXEL HEROES MBTI
## 최종 구현 기준 기획서

> 기준 파일: `심리테스트_v4.html`  
> 이 문서는 최종 HTML에 실제 구현된 화면과 기능을 기준으로 정리한 기획서입니다.

## 1. 프로젝트 개요

### 프로젝트명
**PIXEL MBTI**

### 콘셉트
동화 속 판타지 세계를 모험하며 12개의 질문에 답하고, 답변 결과에 어울리는 MBTI 유형과 픽셀아트 캐릭터를 만나는 가벼운 성격 테스트입니다.

### 대상 사용자
- 가볍게 성격 테스트를 해 보고 싶은 사람
- 귀여운 픽셀아트와 동화 속 판타지 분위기를 좋아하는 사람
- PC와 모바일에서 간편하게 이용하고 싶은 사람

### 사용 목적
- 판타지 모험 상황을 통해 자신의 성향을 가볍게 돌아봅니다.
- 12개 질문의 답변을 바탕으로 16개 MBTI 유형 중 하나와 캐릭터를 보여 줍니다.
- 검사 결과는 재미와 자기이해를 위한 참고 자료이며, 공식 MBTI 검사나 심리 진단을 대체하지 않습니다.

## 2. 구현 환경 및 작동 방식

- HTML 파일 하나로 실행합니다.
- HTML, CSS, JavaScript를 한 파일에 포함합니다.
- 별도의 서버, 로그인, 데이터베이스, 외부 API를 사용하지 않습니다.
- 16개 캐릭터 이미지는 WebP 형식의 Base64 데이터로 HTML 내부에 포함합니다.
- 배경음악은 별도 음원 파일을 불러오는 방식이 아니라 Web Audio API로 생성하는 칩튠 음악입니다.
- 웹 폰트는 Google Fonts를 연결하도록 작성되어 있습니다. 따라서 폰트가 이미 설치되어 있지 않은 환경에서는 인터넷 연결 여부에 따라 지정 폰트의 표시가 달라질 수 있습니다.
- PC 화면을 우선으로 구성하되, 작은 화면에서도 콘텐츠와 버튼을 이용할 수 있도록 반응형 스타일을 적용합니다.

## 3. 화면 구성 및 동작

### 3-1. 시작 화면

- 화면 제목: **당신이 동화 속 주인공이라면?**
- 영문 문구: `A LITTLE FANTASY ADVENTURE`
- 소개 문구: "당신은 어떤 세계에서 어떤 모습으로 살아갈까요?"
- 안내 문구: "당신만의 이야기를 시작해 보세요."
- 하단 표기: `PIXEL HEROES MBTI`
- `모험 시작하기` 버튼을 누르면 첫 번째 질문 화면으로 이동합니다.
- 시작 화면에는 별빛, 픽셀 달, 구름 등의 판타지 배경 효과가 표시됩니다.
- 화면 오른쪽 위의 배경음악 버튼으로 음악을 재생하거나 정지할 수 있습니다.
- 처음 `모험 시작하기`를 누르면 배경음악이 자동으로 재생되도록 설정되어 있습니다.

### 3-2. 질문 화면

- 총 12개 질문을 한 번에 하나씩 보여 줍니다.
- 상단에 현재 진행 상황(예: `1 / 12`)과 진행 바가 표시됩니다.
- 각 질문에는 A와 B 두 가지 선택지가 제공됩니다.
- 선택지를 누르면 답변이 저장되고 다음 질문으로 이동합니다.
- 선택한 답변은 초록색 배경으로 표시됩니다.
- `이전 질문` 버튼을 누르면 직전 질문으로 돌아가며, 기존 선택 답변도 유지됩니다.
- 첫 번째 질문에서는 `이전 질문` 버튼이 비활성화됩니다.
- 마지막 질문에 답하면 결과 화면으로 이동합니다.

### 3-3. 결과 화면

- 계산된 MBTI 네 글자를 표시합니다.
- 해당 유형의 캐릭터 이미지, 이름, 역할 키워드, 성격 소개, 캐릭터 대사를 보여 줍니다.
- 캐릭터 주변에 빛망울과 별빛 도트 효과가 나타나며, 결과가 표시될 때 캐릭터 주변에서 도트 폭죽 효과가 재생됩니다.
- `이미지로 저장` 버튼으로 결과 카드를 PNG 이미지로 저장하거나 모바일 공유 기능을 이용할 수 있습니다.
  - PC 등 일반적인 포인터 환경에서는 PNG 파일을 다운로드합니다.
  - 모바일 등 터치 환경에서는 파일 공유 기능을 지원하는 경우 공유 창을 엽니다.
- `다시 테스트하기` 버튼을 누르면 답변과 진행 상태를 초기화하고 시작 화면으로 돌아갑니다.
- 결과 화면에서는 배경음악 버튼이 표시되지 않습니다.

## 4. 질문 및 MBTI 계산 방식

### 4-1. 질문 구성

질문은 판타지 세계의 모험 상황으로 구성되어 있으며, 각 질문의 A/B 선택지는 아래 성격 차원에 대응합니다.

| 질문 | 성격 차원 | A 선택 | B 선택 |
|---|---|---|---|
| 1 | E / I | E | I |
| 2 | E / I | E | I |
| 3 | E / I | E | I |
| 4 | S / N | S | N |
| 5 | S / N | S | N |
| 6 | S / N | S | N |
| 7 | T / F | T | F |
| 8 | T / F | T | F |
| 9 | T / F | T | F |
| 10 | J / P | J | P |
| 11 | J / P | J | P |
| 12 | J / P | J | P |

### 4-2. 실제 질문과 선택지

**1. 오늘은 길드의 휴일! 동료들이 함께 시간을 보내자고 한다.**
- A: 광장에 새로 열린 야시장에 가보기로 한다. 무슨 재미있는 일이 있을지 궁금하다.
- B: 숲속 작은 여관에 가보기로 한다. 창가 자리에 앉아 따뜻한 차를 마시고 싶다.

**2. 모험 도중 예상치 못한 난관을 만났다. 당신은 어떻게 할까?**
- A: 동료들과 이야기를 나누며 해결 방법을 찾아본다.
- B: 잠시 혼자 생각을 정리한 뒤 해결 방법을 제안한다.

**3. 긴 모험을 마치고 마을로 돌아왔다. 가장 하고 싶은 일은?**
- A: 주점에 들러 다른 모험가들과 오늘의 모험담을 나눈다.
- B: 아늑한 숙소에서 조용히 쉬며 나만의 시간을 보낸다.

**4. 마법 학교에서 새로운 마법을 배우게 되었다. 당신은?**
- A: 마법의 사용법과 실제 시전 방법부터 차근차근 익힌다.
- B: 마법에 숨겨진 원리와 아직 밝혀지지 않은 가능성부터 상상한다.

**5. 오래된 모험가가 당신에게 신비로운 이야기를 들려준다. 어떤 이야기가 더 흥미로울까?**
- A: 실제로 보물을 발견하고 돌아온 모험가의 생생한 경험담.
- B: 아직 아무도 발견하지 못한 전설의 왕국과 숨겨진 세계에 관한 이야기.

**6. 고대 유적에서 정체를 알 수 없는 장치를 발견했다. 당신은?**
- A: 장치의 구조와 작동 순서를 살펴보며 하나씩 작동시켜 본다.
- B: 장치가 만들어진 목적과 이것이 숨기고 있을 비밀을 먼저 추측한다.

**7. 왕궁에서 두 상인이 다투고 있다. 한 사람은 규칙을 어겼고, 다른 한 사람은 억울한 사정이 있다고 주장한다.**
- A: 무슨 일이 있었는지 차례대로 확인하고 규칙에 따라 판단한다.
- B: 두 사람이 처한 상황을 듣고 서로 납득할 수 있는 방법을 찾아본다.

**8. 동료가 실수로 길드의 소중한 마법 수정을 깨뜨렸다. 모두가 당황한 가운데 동료는 아무 말도 하지 못한다.**
- A: 우선 깨진 수정을 살펴보고 복구할 방법을 찾아본다.
- B: 동료에게 괜찮다고 말하며 무슨 일이 있었는지 들어본다.

**9. 던전의 마지막 방에 도착했다. 열쇠는 하나뿐이고 두 개의 문이 있다. 한쪽에는 보물이, 다른 쪽에는 갇힌 정령이 있을지도 모른다.**
- A: 두 문에 남겨진 흔적을 비교해 어느 쪽에 무엇이 있는지 확인한다.
- B: 갇혀 있을지도 모를 정령을 먼저 구해야겠다는 생각이 든다.

**10. 드디어 새로운 왕국으로 여행을 떠나는 날이다.**
- A: 지도에 표시된 유명한 명소와 숙소를 확인하고 출발한다.
- B: 일단 길을 나선 뒤 마음에 드는 마을이 나타나면 머물기로 한다.

**11. 마을에서 큰 축제가 열린다. 당신은 축제 준비를 도와달라는 부탁을 받았다.**
- A: 장식, 음식, 공연 순서까지 미리 정해두고 준비를 시작한다.
- B: 광장을 돌아다니며 필요한 일을 발견할 때마다 하나씩 돕는다.

**12. 오래된 예언서의 마지막 장이 발견되었다. 하지만 마지막 문장은 누군가 찢어버린 듯 사라져 있다.**
- A: 남아 있는 기록을 모아 예언의 결말을 완성해 본다.
- B: 아직 정해지지 않은 결말이라 생각하고 새로운 가능성을 떠올린다.

### 4-3. 계산 규칙

- 각 성격 차원은 3개 질문으로 구성됩니다.
- 각 차원에서 A를 선택한 개수를 계산합니다.
- A가 2개 이상이면 해당 차원의 첫 번째 알파벳을 선택하고, 그렇지 않으면 두 번째 알파벳을 선택합니다.
- 따라서 각 차원은 다음과 같이 계산됩니다.
  - 1~3번: A가 2개 이상이면 E, 아니면 I
  - 4~6번: A가 2개 이상이면 S, 아니면 N
  - 7~9번: A가 2개 이상이면 T, 아니면 F
  - 10~12번: A가 2개 이상이면 J, 아니면 P
- 네 차원의 결과를 조합해 16개 유형 중 하나를 표시합니다.
- 차원마다 질문이 3개이므로 동점은 발생하지 않습니다.

## 5. 캐릭터 구성

캐릭터는 16개 MBTI 유형에 각각 한 명씩 연결되어 있습니다. 캐릭터의 이름, 역할 키워드, 성격 소개, 대사는 HTML의 캐릭터 데이터에 등록되어 있습니다.

| 유형 | 이름 | 역할 키워드 |
|---|---|---|
| INTJ | 아르덴 | 별빛의 설계자 |
| INTP | 루미 | 호기심의 연금술사 |
| ENTJ | 카이엘 | 왕국의 전략가 |
| ENTP | 테오라 | 상상의 발명가 |
| INFJ | 세레나 | 달빛의 예언자 |
| INFP | 엘로이 | 꿈을 수집하는 시인 |
| ENFJ | 에이든 | 마음을 잇는 이야기꾼 |
| ENFP | 피오나 | 별을 쫓는 모험가 |
| ISTJ | 에드윈 | 왕립 도서관의 기록관 |
| ISFJ | 로제 | 숲속의 약초사 |
| ESTJ | 로웬 | 왕국의 수호대장 |
| ESFJ | 마리엘 | 축제의 주인장 |
| ISTP | 레온 | 고요한 숲의 장인 |
| ISFP | 이슬라 | 꽃길을 걷는 방랑자 |
| ESTP | 제이든 | 황금빛 모험가 |
| ESFP | 벨라 | 별빛 축제의 연주자 |

### 캐릭터 이미지 적용

- 16개 유형의 캐릭터 이미지가 HTML 내부에 Base64 형식으로 포함되어 있습니다.
- 이미지 형식은 WebP입니다.
- 결과 화면에서 계산된 유형에 해당하는 이미지가 자동으로 표시됩니다.
- 캐릭터 이미지가 연결되지 않은 경우를 대비해 이미지 대체 문구를 표시하는 처리도 포함되어 있습니다.
- 기획 단계에서 별도로 이미지를 불러오거나 이미지 폴더를 함께 배포할 필요가 없습니다.

## 6. 디자인 및 시각 효과

### 디자인 방향
- 세계관: 별빛이 머무는 동화의 숲과 판타지 모험
- 그림체: 귀여운 픽셀 RPG 스타일
- 분위기: 귀여움과 신비로운 판타지가 섞인 분위기
- 주요 색상: 라벤더, 하늘색, 핑크, 크림색
- 보조 색상: 숲의 초록색, 나뭇잎 색상, 별빛을 표현하는 노란색
- 화면 형태: 중앙 정렬형 콘텐츠와 픽셀 테두리·그림자 효과

### 화면별 효과
- 배경은 짙은 보라색에서 라벤더와 핑크로 이어지는 그라데이션으로 구성합니다.
- 시작 화면과 질문 화면에는 픽셀 달, 구름, 반짝이는 별 도트가 움직입니다.
- 결과 화면에는 빛망울, 별똥별, 떨어지는 별빛 도트와 캐릭터 주변의 도트 폭죽 효과가 나타납니다.
- 캐릭터는 결과 화면에서 등장 애니메이션과 위아래로 움직이는 효과가 적용됩니다.
- 사용자의 운영체제에서 동작 줄이기 설정을 사용하면 애니메이션을 줄이도록 처리합니다.

## 7. 배경음악

- 별도의 음악 파일을 사용하지 않고 JavaScript와 Web Audio API로 칩튠 음악을 생성합니다.
- 음악은 반복 재생됩니다.
- 화면 오른쪽 위의 `♪ 재생` / `♪ 정지` 버튼으로 사용자가 직접 제어할 수 있습니다.
- 첫 번째 `모험 시작하기` 버튼을 누르면 음악이 자동 재생됩니다.
- 결과 화면에서는 배경음악 버튼을 숨깁니다.

## 8. 결과 이미지 저장

- 결과 화면의 `이미지로 저장` 버튼을 누르면 결과 카드와 동일한 핵심 정보가 담긴 PNG 이미지를 별도로 생성합니다.
- 저장 이미지에는 배경 그라데이션, 별빛 도트, 픽셀 달과 구름, MBTI 유형, 캐릭터 이미지, 이름, 역할 키워드, 성격 소개, 대사가 포함됩니다.
- 이미지 크기는 1080 × 1620 픽셀입니다.
- PC에서는 PNG 파일 다운로드를 시도합니다.
- 모바일에서는 브라우저가 파일 공유를 지원하면 공유 창을 엽니다.
- 저장 중에는 버튼을 비활성화하고, 오류가 발생하면 안내 메시지를 표시합니다.

## 9. 데이터 및 개인정보 처리

- 답변은 현재 페이지가 열려 있는 동안 JavaScript 변수에 보관됩니다.
- 답변을 서버로 전송하거나 외부에 저장하지 않습니다.
- 로그인이나 개인정보 입력 절차가 없습니다.
- 별도의 결과 기록, 통계, 사용자별 저장 기능은 구현하지 않았습니다.
- 새로고침하거나 페이지를 다시 열면 테스트를 처음부터 진행해야 합니다.
- `다시 테스트하기` 버튼을 누르면 기존 답변을 초기화합니다.

## 10. 한계 및 비목표

1. 공식 MBTI 검사 도구가 아니라 재미와 자기이해를 위한 간단한 테스트입니다. 진단이나 상담 목적으로 사용할 수 없습니다.
2. 질문이 총 12개이며 각 차원은 3개 질문으로만 구성되어 있어 개인의 성향을 세밀하게 측정하지 않습니다.
3. 결과는 16개 유형 중 하나의 네 글자 유형과 캐릭터 설명으로 제시합니다. 차원별 점수나 성향의 강도, 불확실성은 제공하지 않습니다.
4. 답변과 결과를 서버에 저장하거나 통계로 수집하지 않습니다.
5. 결과를 다시 확인할 수 있는 별도의 결과 보관함이나 공유용 URL은 제공하지 않습니다. 결과 공유는 PNG 저장 또는 모바일 공유 기능을 이용합니다.
6. 외부 API, 로그인, 데이터베이스, 별도 서버 연동은 구현 범위에 포함하지 않습니다.
7. 웹 폰트 연결에는 외부 네트워크가 사용될 수 있으나, 질문·계산·캐릭터 이미지 등 테스트의 핵심 데이터는 HTML 파일 내부에 포함되어 있습니다.

- [ ] 질문 진행 숫자와 진행 바가 현재 질문에 맞게 바뀌는가?
- [ ] A/B 선택 후 다음 질문으로 이동하는가?
- [ ] 이전 질문으로 돌아갔을 때 기존 선택이 유지되는가?
- [ ] 첫 번째 질문에서 이전 질문 버튼이 비활성화되는가?
- [ ] 12개 답변에 따라 MBTI 네 글자가 올바르게 계산되는가?
- [ ] 16개 유형 각각에 맞는 캐릭터 이미지와 정보가 표시되는가?

- [ ] `이미지로 저장` 버튼으로 PNG가 생성되거나 모바일 공유 창이 열리는가?
- [ ] `다시 테스트하기`를 누르면 답변이 초기화되고 시작 화면으로 돌아가는가?

- [ ] PC와 모바일 화면에서 글자나 버튼이 잘리거나 겹치지 않는가?
- [ ] HTML 파일 하나만으로 테스트의 핵심 기능이 작동하는가?
